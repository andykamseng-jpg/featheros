    Feather code updates

    Owner and final leader: Mother. Feather can apply its own source updates automatically; each update is kept as a FOSCP code patch for you to inspect or roll back.

    F2F sync starts automatically. Devices find each other on the same private network and poll the Feather relay for other networks; no address, key, or owner passcode is needed for code sync. Compatible source changes travel as FOSCP code messages, not installers or source bundles.

    Updates are checked for source base hashes, resulting hashes, Python/JSON syntax, and hardware compatibility before application. The internet relay stores messages privately for up to 30 days and checks every five minutes. It currently has no owner-group authorization, so any Feather installation using this public relay can publish code. Hash and syntax checks do not prove who authored a patch or run the full test suite. Same-network peer traffic is not encrypted, so use direct discovery only on a trusted network.
